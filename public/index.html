功能特性

七大核心模块，前后端完整闭环

用户登录认证

基于 Express + Session 的登录认证系统，密码校验、会话管理、登出销毁全流程覆盖。

赛博能量爆特效

自研 Canvas 粒子系统：三层粒子 + 电弧 + 多环冲击波 + 色差重影，登录失败时全屏连锁引爆。

内置扫雷游戏

登录成功即可游玩经典扫雷，9×9 棋盘、右键插旗、计时挑战、胜负判定一应俱全。

用户数据表格

登录后展示数据库中的用户列表，包含 ID、用户名、邮箱、注册时间等字段。

注册与用户管理

开放注册新账号，管理员可在后台新增、编辑、删除用户并分配角色；登录后还可在个人中心修改自己的邮箱与密码。

SQLite 数据库

使用 better-sqlite3 同步操作数据库，无需额外安装数据库服务，开箱即用。

失败死亡界面

输错密码触发全屏连环爆炸、白光过曝与随机衰减震动，弹出「你被炸死了」死亡界面。
