设计原则

四条原则决定了界面上每一个像素的取舍。

1 · 暗色优先，玻璃承载

深空渐变作底，毛玻璃卡片承载内容。层级靠透明度与模糊区分，而非靠边框堆叠。

2 · 令牌驱动，禁止裸值

任何颜色、间距、圆角、时长都走 var(--token)。改一处，全站同步。

3 · 状态可感知

hover / active / focus / loading / disabled 五态齐全，键盘用户能看到焦点环。

4 · 克制使用动效

动效只用于解释因果（反馈、转场），不用于炫技。尊重 prefers-reduced-motion。

规范清单
  • 所有交互元素可键盘聚焦，且焦点环可见（不移除 outline 而改用 box-shadow 焦点环）
  • 图标按钮带 aria-label；纯装饰图标容器加 aria-hidden
  • 表单控件与 label 通过 for / id 关联
  • 尊重 prefers-reduced-motion：开启后动效时长归零
  • 状态不只靠颜色传达（徽章同时带文字与边框）
